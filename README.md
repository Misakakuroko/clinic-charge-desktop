# 门诊收费录入打印软件

这是根据需求答卷制作的 Windows 单机离线软件（v0.1.1）。它不联网，不开具具有法律效力的医疗收费票据，只生成内部收费或治疗清单。

## 直接下载 Windows 版

[下载最新 Windows x64 离线包](https://github.com/Misakakuroko/clinic-charge-desktop/releases/latest/download/ClinicCharge-Windows-x64.zip)

下载后请完整解压，再双击文件夹内的 `ClinicCharge.exe`。不要只把 EXE 单独复制出来。

首版闭环：

- 维护收费项目目录，也允许本单临时项目；
- 录入患者姓名和收费明细，按单价 × 数量计算两位小数金额；
- 保存项目快照，目录后来改名或改价不会影响历史单据；
- 草稿确认后锁定，可查看、补打、作废和作废重开；
- 按患者姓名、收款日期和内部流水号组合查询；
- 空白纸完整打印，支持纸张尺寸与偏移校准；90×90 mm 套打档案暂保留设置，提供空白票纸并定稿前禁止正式套打；
- 桌面版数据保存在当前 Windows 用户的应用数据目录，并支持手动导入、导出备份。

## v0.1.1 稳定性改进

- 错误或空白单价、零数量、超过精度的数字会明确提示，不会偷偷改成 0 或 1。
- 保存按顺序执行；新建、切换正在编辑的单据和关闭时提示处理未保存修改。
- 每次保存保留上一份有效数据；启动读不到数据时，可在恢复页重试或选择备份。
- 导入前校验备份并显示记录数量；恢复前另存原数据，选错普通 JSON 不会清空记录。
- 历史列表每页 50 条；一万张、每张五个项目的数据纳入自动回归。
- 草稿与作废单据打印明显标识；超出单张纸范围时禁止打印，避免漏打合计。

## 更新与备份

1. 在旧版“打印设置”中导出备份，妥善保存到其他磁盘或 U 盘。
2. 关闭旧版，下载新版并解压到新文件夹，再运行新版 EXE。不要同时运行两个版本。
3. 同一台电脑、同一个 Windows 用户会自动读取原数据，不需要反复导入。
4. 换电脑或 Windows 用户时，请用手动导出的 JSON 备份迁移，不要直接复制加密数据文件。

“打印设置 → 数据文件夹”可查看实际位置。自动副本与主文件在同一磁盘，只能应对部分误操作和写入故障，不能防止硬盘损坏。手动备份是明文，含姓名和收费记录，请勿发到公开仓库或公开链接。

本版从 16,000 张开始提醒，20,000 张后暂停新增；已有数据仍可读取和导出。接近上限时联系维护者处理，不要自行删除数据文件。

## 开发运行

```bash
npm install
npm run check
npm start
```

## 生成 Windows 便携版

```bash
npm run package:win
npm run test:windows
```

输出位于 `release/ClinicCharge-win32-x64/`。整个目录复制到 Windows 10/11 x64 电脑后，双击 `ClinicCharge.exe` 即可运行，无需联网安装依赖。

## 打印定稿前仍需现场材料

- 确认 241×140 mm 是纸张外尺寸、210×140 mm 是否为有效内容区；
- 90×90 mm 无遮挡空白票据；
- 匿名合格成品照片；
- 富士通 DPK800 铭牌或完整型号后缀照片；
- 实际纸张配尺照片。

在材料到位前，页面尺寸和 X/Y 偏移均可调整，套打被明确标为待定稿。本软件尚未通过 DPK800 实机打印验收；请先用虚构姓名和普通纸试印。

## 发布检查

GitHub 的 Windows 检查会运行自动测试、打包实际 EXE，在隔离数据目录中启动、录入、保存并重启查询。验收数据均为虚构资料，不会读写实际患者数据。实际打印机与纸张仍需现场验收。
